#  File Type Identifier & CyberSec Tools

##  Описание
В кибербезопасности нельзя доверять расширению файла, так как злоумышленник может легко переименовать вредоносный `.exe` в безобидный `.jpg`. 
**File Type Identifier** - это утилита командной строки (CLI) на Python, которая определяет истинный формат файла, анализируя его сырые байты («магические числа» или Magic Numbers) в заголовке.

Этот репозиторий также служит моим портфолио, куда будут добавляться новые скрипты по мере изучения программирования для задач кибербезопасности.

##  Возможности скрипта
* **Безопасное чтение бинарных данных:** Считывает только первые 16 байт файла, что предотвращает переполнение памяти при анализе огромных файлов.
* **Сверка по словарю сигнатур:** Определяет форматы JPEG, PNG, PDF и другие.
* **Анализ Bash-скриптов:** При обнаружении шебанга (`#!`) скрипт автоматически распознает `.sh` файл и выводит его текстовое содержимое для анализа.
* **Непрерывная работа (Loop):** Инструмент работает в бесконечном цикле, позволяя проверять файлы один за другим без перезапуска программы.
* **Защита от сбоев (Error Handling):** Встроенный перехват исключений (`try/except`) предотвращает аварийное завершение работы, если указан неверный путь к файлу.

##  Установка и использование

1. Убедитесь, что у вас установлен **Python 3.x**.
2. Склонируйте репозиторий или скачайте файл скрипта.
3. Запустите скрипт через терминал:
```bash
  python file_type_identifier.py
```
4. Введите путь к исследуемому файлу (например: test.pdf или /home/user/Downloads/file).
